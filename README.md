# 词跃 WordQuest

把「每天背 20 个单词」变成「每天打一局有进度感的游戏」——而每一局都在真实推进你的记忆曲线。

纯静态前端应用，`npm run build` 的产物可直接部署到任何服务器。

---

## 特性

**学习内核**
- FSRS-4.5 间隔重复算法：每张卡片维护 `stability` / `difficulty`，按四档自评（忘了 / 有点难 / 记得 / 太简单）计算下次到期时间
- 每日队列 = 到期复习 + 新词 + 薄弱词，按「每 3 个复习插 1 个新词」交错排列，避免连续陌生词带来的挫败感
- 掌握度判定：`stability ≥ 21 天 且 lapses ≤ 2`
- 单词卡：音标 / 假名读音、TTS 朗读、例句与翻译、下次间隔预览
- 待复习：首页「待复习」数字与卡片可点，直接进入纯复习模式（`/learn?mode=due`）；词库页每个词包也显示自己的待复习数，点了就只复习这个词包（`/learn?mode=due&deck=xxx`）。数字与队列同源于 `dueItems()`，并且只统计当前在学的词库

**游戏（4 款，全部可玩）**
- **坠落词云**（Canvas 60fps）：释义气泡下落，点击或按 1/2/3 送进正确的单词跑道；3 条命、连击倍率 1x→2.5x、答错扣命、气泡触底判超时。一局 60 秒
- **词魔塔**：看词选义，90 秒内打空 220 点血量的「遗忘恶魔」；答错被反击扣血，每第 5 题出精英词（从 `lapses > 0` 的薄弱词里抽）造成双倍伤害
- **拼写工坊**：看释义用乱序字母块拼词，可直接键盘输入、退格撤回；3 次提示，拼错两次自动揭示答案。日语按假名读音拼
- **听音辨词**：TTS 播报后四选一，支持 0.75x / 1x / 1.25x 语速；无语音合成的浏览器降级显示音标
- **四款游戏共用同一套判分与回写**：结算时批量产出 ReviewLog 并更新每张卡的下次到期时间，玩游戏 = 复习

**多语言 · 词库**
- 内容语种：英语 17 本 + 日语 5 本 + 西班牙语 2 本，共 **24 本词书 57,360 词**，全部为真实词条（词 + 音标/假名 + 词性 + 释义，高频词带例句与译文）
- 每本书都是**完整规模**，没有几十词的迷你书：四级 2607、六级 2345、考研 3725、专八 12197、托福 4264、GRE 6514……
- 界面语言：简体中文 / English，全部文案走字典，无硬编码

- **数据来源**：[qwerty-learner](https://github.com/Kaiyiwing/qwerty-learner) 的 `public/dicts`（CET4_T / CET6_T / KaoYan_3_T / IELTS_3_T / TOEFL_3_T / GRE_3_T / Level4 / Level8 / GaoKao_3500 / ChuZhongluan / ZhongKaoHeXin / PEPXiaoXue 3-6 / JapVocabList N5-N1）。原始 JSON 放在 `.dicts/`，执行 `node scripts/gen-corpus.mjs` 会重新生成 `public/corpus/`
- 自然拼读三本书是从小学到考研的全部词表里按拼写规则（CVC / Magic E / 辅音组合）筛出的真实短词，不是编造的词根练习
- 西语没有公开大纲，`src/data/words.es.extra.ts` 是手写的 A1/A2 主题词表（问候、数字、时间、身体、饮食、家居、地点、交通、动作、形容、颜色、连接）
- 同一单词在多本书里都出现时，队列按「语言 + 拼写」去重，只出一张卡，并优先保留带例句的那条

**2 万词级语料怎么不拖慢首屏**
- 57,360 条词条共 3.8 MB，不能塞进 JS bundle。所以语料按词书分片放在 `public/corpus/<deckId>.json`，另有一份 8.6 KB 的 `index.json`
- 启动分两段：先拉索引（2.5 KB，几十毫秒）→ 再拉 `activeDecks` 那几本。启动画面显示的是**真实进度**（正在装载哪本、第几本 / 共几本），不再是无意义的循环动画
- 全量语料**绝不跟首屏抢带宽**：早先索引一到就在 idle 里拉 24 本共 1.8 MB，弱网下会把一个 90 KB 的首屏拖成好几秒；现在改成页面静置 12 秒、或用户第一次动手之后 2.5 秒才补，且 3 路并发 + `priority: low`。搜索框聚焦会直接触发，不会漏
- 实测首屏（1440×940，冷缓存，CDP 限速）：4G 约 0.75 s、Fast 3G 约 1.6 s、Slow 3G 约 5.6 s（单本 213 KB 关键路径）；二次访问词书走 HTTP 缓存，约 0.07 s
- 单本词书加载失败（比如部署时漏传分片）不再让启动画面永久卡住——标记失败后照常进主界面，下次有人用到这本书时会重试
- 主 bundle 因此只有 **208 KB（gzip 58 KB）**，比把所有词打包进去小了 20 倍
- 索引用 `cache: no-cache` 每次校验（换词表后能立刻生效），词书分片用默认缓存

**全局搜索（⌘K / Ctrl+K）**
- 任意页面按 ⌘K 唤起，侧栏有入口，移动端顶部有常驻搜索条
- 命中范围：英文拼写、中文释义、音标（去重音符号，`kənˈsɪdə` 能搜到 consider）、假名
- 打分：完全匹配 1000 → 前缀 900（越短越靠前）→ 词形变化 850 → 子串 700 → 释义 620/560 → 音标 480 → 子序列 fuzzy 260；同分时优先带例句、已学过的
- 英文按「语言 + 拼写」聚合，同一个词不会因为出现在五本书里就刷屏
- 结果支持 ↑↓ 选择、Enter 进详情（音标 / 朗读 / 释义 / 例句 / 所属词书 / 下次复习间隔 / 一键问 AI），Esc 逐层退出

**语法练习**
- 10 个专题 × 8 题 = 80 道，覆盖时态、被动、定语从句、非谓语、虚拟语气、冠词、介词、主谓一致、比较级
- 四个选项，选完立刻判对错并给出**一句中文解析**；一轮结束有得分、评语和错题回顾（红色是选错项，绿色是正确答案）
- 难度按 CEFR 标注（A2 → C1），专题卡片上显示做过的正确率；进度存 `wordquest-grammar-v1`，只在本机
- 题库在 `src/data/grammar.ts`，加一个专题就是往 `GRAMMAR_TOPICS` 里 push 一个对象
- PC 在侧栏进，移动端从首页「快捷模式 → 语法」进（底栏保持五个位置）

**AI 助手**
- 右下角悬浮入口，PC 是右侧抽屉，移动端是全屏面板；不联网也能用
- 本地引擎覆盖：查词（含词根词缀拆解）、今日该学什么、薄弱词、学习数据、推荐词书、出题（四选一，可作答判分）、改每日目标
- 想让助手回答开放问题，可在「设置 → AI 助手 · 大模型」填任意 OpenAI 兼容接口（OpenAI / DeepSeek / Moonshot / 本地 Ollama），带「测试连接」；Key 只存在本机 localStorage，浏览器直连，不经过任何中间服务器
- 大模型失败时自动回退到本地引擎，并把本地答案贴在下面，不会出现空白回复

**首页（学习仪表盘）**
- 顶部：问候 + 连续天数 + 单词速查（输入中文或英文即时出结果，点开看音标、例句、下次复习时间，可朗读；按 Enter 直接跳到全量搜索）
- 今日计划卡：当前词书进度、今日新词 `n/每日目标`、待复习 `已复习/总量`，两个主按钮直达 `/learn` 与 `/learn?mode=due`
- 快捷模式：单词卡 / 到期复习（带红点计数）/ 四款游戏 / 词库 / 数据统计，共 8 格
- 右栏：词灵养成、近 7 天复习量、在学词书（多本同时学时的进度与各自待复习数）、薄弱词

**词库页（选择词书）**
- PC 三栏：学段竖排导航（带各段待复习红点）+ 词书列表 + 选中词书的详情面板（词条预览 / 三项统计 / 进度 / 开始学习）
- 移动端：学段胶囊 + 词书列表，点卡片弹出底部详情抽屉
- 一级分类 11 个学段共 24 本书（每本都是完整词表），二级 pill 按「系列」再筛（全部 / 拼读规则 / 人教版 / 核心词 / 高频词 / 雅思 / 托福 / GRE / 专四 / 专八 / JLPT / DELE），PC 另有「推荐 / 词数 / 进度」排序
- 每本书一行：CSS 书封 + 书名 + 简介 + 词数（来自语料索引，无需先下载词条）+ 完成度 + 待复习胶囊；某个学段只有一本时卡片自动占满整行
- 列表下方是「换个方向」跨学段推荐，避免某分类只有一两本时页面太空
- 全程使用主站主题变量（深色 / 浅色都跟着变），不再有独立的暖色纸面

**元游戏**
- 经验值 / 等级、宝石、连续天数、14 个成就
- 词灵 Lexi 六段进化（词蛋 → 星辉兽），把「背会了」变成可见的成长

**工程**
- 响应式：移动端底部 tab，桌面端侧边栏
- 深色 / 浅色双主题，CSS 变量驱动
- 数据全部存 `localStorage`，可导出 JSON 备份
- 零后端依赖，零外部字体与图片请求（图标为内联 SVG，音效由 Web Audio 实时合成）
- 大纲全量词表单独打包为 `dicts` chunk（660KB / gzip 300KB），与业务代码分开缓存，业务改动不会让词表缓存失效

## 数据模型速览

```ts
CardState {
  stability: number      // 记忆稳定度（天）：遗忘到 90% 所需时间
  difficulty: number     // 1-10
  due: number            // 下次到期时间戳
  reps / lapses          // 总复习次数 / 遗忘次数
  state: 'new' | 'learning' | 'review' | 'relearning'
  mastered: boolean
}
```

排程公式（FSRS-4.5，`src/lib/srs.ts`）：

- 可提取概率 `R(t) = (1 + t / (9·S))⁻¹`
- 成功复习：`S' = S · (1 + e^w8 · (11-D) · S^-w9 · (e^{w10(1-R)} - 1) · hardPenalty · easyBonus)`
- 遗忘：`S' = w11 · D^-w12 · ((S+1)^w13 - 1) · e^{w14(1-R)}`

## 已知边界

- 数据仅存本地，换设备不同步（要同步需接后端，模型与 API 设计见 `../WordQuest-完整方案.md`）
- 游戏已全部上线（坠落词云 / 词魔塔 / 拼写工坊 / 听音辨词），四款共用同一套判分与 SRS 回写
- 发音走在线音频直链，**需要联网**；断网时英文会退到系统 TTS，若系统没装英文本地语音包可能无声（Windows 设置里加 English (United States) 的语音即可）。西语暂无可用直链，一直走系统 TTS
- 音频接口被墙或被改时会自动静默失败，不影响其他功能（`src/lib/audio.ts` 里换 URL 即可）
